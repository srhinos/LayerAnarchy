# Layer Anarchy

Swap layers on WoW Forever through every layer network at once, and host for all of them. No rules but the game's.

- Talks to LayerSwap and its forks (Bulo Layer Forever, Forever Simple Layer), AutoLayer, VoidNet and Forever Layer Hop.
- No combat, death or guessed hourly-cap blocks. It learns the real limit from your own swaps and counts down to the reset when the game refuses.
- One small box: your layer, a live status line, Host and Swap. The bars open network stats, the cog opens options. Minimizes to a HUD.

`/la` toggles the box, `/la swap` swaps, `/la diag` prints a report. Key bindings are under Layer Anarchy.

Layer Anarchy turns itself off if another layer addon is loaded.

GPL-3.0. Written from scratch; other addons' message formats are used only to interoperate.
